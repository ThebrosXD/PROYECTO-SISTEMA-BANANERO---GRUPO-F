# 🍌 PROYECTO SISTEMA BANANERO – GRUPO F

Sistema de gestión para el control de procesos en una empresa bananera, desarrollado como parte de un proyecto académico por el Grupo F.

## Descripción

Este sistema permite administrar eficientemente los procesos relacionados con la producción, empaque y exportación de banano. Incluye módulos para el manejo de usuarios, roles, productos, pedidos y reportes.

## 🛠️ Tecnologías utilizadas

- Java
- Spring Boot
- MySQL
- HTML/CSS
- JavaScript
